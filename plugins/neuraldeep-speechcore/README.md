# neuraldeep-speechcore

Wallet-approved recording uploads and resumable transcripts. Subscription uploads remain blocked.

The skill and its guarded helper are in [skills/neuraldeep-speechcore/](skills/neuraldeep-speechcore/README.md).

Source commit [3f33a8fa44c692329ce3b2b2670eabeb29cfef22](https://github.com/viktor-drobek/neuraldeep-speechcore/commit/3f33a8fa44c692329ce3b2b2670eabeb29cfef22).
Runtime files are copied unchanged from that public source. See the root catalog.json for SHA-256 hashes.
Installing this package does not authorize paid API calls or override blocked operations.

```text
/plugin install neuraldeep-speechcore --marketplace viktor-drobek/neuraldeep-skills-marketplace
```

```bash
coddy plugin install neuraldeep-speechcore@neuraldeep-skills
```
