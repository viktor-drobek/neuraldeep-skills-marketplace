The skill and its guarded helper are in [skills/neuraldeep-embeddings/](skills/neuraldeep-embeddings/README.md).

Source commit [a481bd3b2f286f596b9a9830cc7eabd576c5a6c4](https://github.com/viktor-drobek/neuraldeep-embeddings/commit/a481bd3b2f286f596b9a9830cc7eabd576c5a6c4).
