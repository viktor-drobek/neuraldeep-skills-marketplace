# neuraldeep-diarization

Guarded speaker diarization and offline merge with timed transcripts.

The skill and its guarded helper are in [skills/neuraldeep-diarization/](skills/neuraldeep-diarization/README.md).

Source commit [74b41e60d162fe97af17aa43a5b1c71aa4274c9e](https://github.com/viktor-drobek/neuraldeep-diarization/commit/74b41e60d162fe97af17aa43a5b1c71aa4274c9e).
Runtime files are copied unchanged from that public source. See the root catalog.json for SHA-256 hashes.

