# neuraldeep-music

Wallet-approved text-to-music, WAV artifacts and resumable jobs. Subscription generation remains blocked.

The skill and its guarded helper are in [skills/neuraldeep-music/](skills/neuraldeep-music/README.md).

Source commit [b55e6d19de5d870d210d00e2e749d3575ed755f5](https://github.com/viktor-drobek/neuraldeep-music/commit/b55e6d19de5d870d210d00e2e749d3575ed755f5).
Runtime files are copied unchanged from that public source. See the root catalog.json for SHA-256 hashes.
Installing this package does not authorize paid API calls or override blocked operations.

```text
/plugin install neuraldeep-music --marketplace viktor-drobek/neuraldeep-skills-marketplace
```

```bash
coddy plugin install neuraldeep-music@neuraldeep-skills
```
