# neuraldeep-books

Catalogue, contents, chapters and full-text search. No vector inference or model-answer calls.

The skill and its guarded helper are in [skills/neuraldeep-books/](skills/neuraldeep-books/README.md).

Source commit [20058271827c5535461ad0d150fd2dd3ef51b4fc](https://github.com/viktor-drobek/neuraldeep-books/commit/20058271827c5535461ad0d150fd2dd3ef51b4fc).
Runtime files are copied unchanged from that public source. See the root catalog.json for SHA-256 hashes.
Installing this package does not authorize paid API calls or override blocked operations.

```text
/plugin install neuraldeep-books --marketplace viktor-drobek/neuraldeep-skills-marketplace
```

coddy plugin install neuraldeep-books@neuraldeep-skills
