# neuraldeep-tts

Wallet-approved WAV speech synthesis with eight voices. Subscription synthesis remains blocked.

The skill and its guarded helper are in [skills/neuraldeep-tts/](skills/neuraldeep-tts/README.md).

Source commit [20b04024e80d4ff797e26c4a371182ef1e8d6b83](https://github.com/viktor-drobek/neuraldeep-tts/commit/20b04024e80d4ff797e26c4a371182ef1e8d6b83).
Runtime files are copied unchanged from that public source. See the root catalog.json for SHA-256 hashes.
Installing this package does not authorize paid API calls or override blocked operations.

```text
/plugin install neuraldeep-tts --marketplace viktor-drobek/neuraldeep-skills-marketplace
```

```bash
coddy plugin install neuraldeep-tts@neuraldeep-skills
```
