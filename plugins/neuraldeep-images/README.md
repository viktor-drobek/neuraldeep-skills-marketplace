# neuraldeep-images

Guarded image generation, upscale, background removal, enhancement and avatars.

The skill and its guarded helper are in [skills/neuraldeep-images/](skills/neuraldeep-images/README.md).

Source commit [0077d67c94bb532c15eea3f980d94a7345d89bab](https://github.com/viktor-drobek/neuraldeep-images/commit/0077d67c94bb532c15eea3f980d94a7345d89bab).
Runtime files are copied unchanged from that public source. See the root catalog.json for SHA-256 hashes.
Installing this package does not authorize paid API calls or override blocked operations.

```text
/plugin install neuraldeep-images --marketplace viktor-drobek/neuraldeep-skills-marketplace
```

```bash
coddy plugin install neuraldeep-images@neuraldeep-skills
```
