# neuraldeep-search

Guarded web search, Telegram search and site crawling with live quota checks.

The skill and its guarded helper are in [skills/neuraldeep-search/](skills/neuraldeep-search/README.md).

Source commit [12fb30e741d0b73ca34558ffc9023880c7f16fef](https://github.com/viktor-drobek/neuraldeep-search/commit/12fb30e741d0b73ca34558ffc9023880c7f16fef).
Runtime files are copied unchanged from that public source. See the root catalog.json for SHA-256 hashes.
Installing this package does not authorize paid API calls or override blocked operations.

```text
/plugin install neuraldeep-search --marketplace viktor-drobek/neuraldeep-skills-marketplace
```

```bash
coddy plugin install neuraldeep-search@neuraldeep-skills
```
