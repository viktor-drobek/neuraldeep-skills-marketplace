# neuraldeep-ocr

Guarded PDF and image OCR with fast/pro profiles, page ranges and resumable jobs.

The skill and its guarded helper are in [skills/neuraldeep-ocr/](skills/neuraldeep-ocr/README.md).

Source commit [6f174b11b2425194ff1da8e466011d3bb6f6fdab](https://github.com/viktor-drobek/neuraldeep-ocr/commit/6f174b11b2425194ff1da8e466011d3bb6f6fdab).
Runtime files are copied unchanged from that public source. See the root catalog.json for SHA-256 hashes.
Installing this package does not authorize paid API calls or override blocked operations.

```text
/plugin install neuraldeep-ocr --marketplace viktor-drobek/neuraldeep-skills-marketplace
```

```bash
coddy plugin install neuraldeep-ocr@neuraldeep-skills
```
